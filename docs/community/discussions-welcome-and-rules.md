# Welcome to AgentNexus Discussions

**欢迎加入 AgentNexus Discussions**

AgentNexus Discussions is the public collaboration space around the Agent
Collaboration Framework (ACF) and its reference implementation.

Our goal is not to build another general chat forum. This is where agent
builders, protocol designers, identity and trust providers, security
researchers, and users can compare real collaboration scenarios, review
protocol semantics, and produce interoperable evidence.

The guiding principle is:

> **Standardize evidence exchange, not trust decisions.**

## Where to post

- **Announcements / 公告** — Project updates, releases, RFC status changes, and
  community summaries.
- **Q&A / 使用问答与概念澄清** — Usage questions, integration troubleshooting,
  and clarification of AgentNexus or ACF concepts.
- **Meet the Agents / 展示你的 Agent** — Introduce your agent, runtime,
  capabilities, and the collaborators you want to connect with.
- **Interoperability Lab / 互操作实验室** — Cross-framework experiments,
  schemas, traces, fixtures, mappings, and interoperability blockers.
- **RFC & Protocol Review / RFC 与协议评审** — Focused review of RFC text,
  protocol semantics, security boundaries, and governance decisions.
- **Use Cases & Ideas / 场景与想法** — Real collaboration scenarios and open
  questions that may span multiple RFCs.

Use Discussions for open questions, exploration, and design work. Once a bug
or task has a clear scope, move it to an Issue. Use Pull Requests for concrete
changes. Do not report security vulnerabilities publicly; follow the
[Security Policy](https://github.com/kevinkaylie/AgentNexus/security/policy).

## Community rules

1. **Challenge ideas, not people.** Be respectful of different projects,
   backgrounds, languages, and levels of experience. English and Chinese are
   both welcome.
2. **Separate claims from evidence.** When describing something as secure,
   trusted, verified, or interoperable, identify the implementation, version,
   test, trace, specification, or other supporting evidence.
3. **Make the scenario explicit.** Trust, evidence, authority, and risk are
   contextual. State who is acting, what action is proposed, and which
   boundary matters.
4. **Humans remain accountable for AI-assisted posts.** Review generated
   content before posting, disclose material agent assistance when relevant,
   and do not use agents to flood discussions or impersonate maintainers.
5. **Protect sensitive information.** Do not post private keys, tokens,
   personal data, confidential prompts, proprietary artifacts, or unredacted
   logs.
6. **Relevant integrations are welcome; promotion-only posts are not.**
   Explain the technical relationship, interoperability question, or lesson
   for the community.
7. **Votes show interest, not protocol truth.** Maintainers will summarize
   evidence, decisions, dissent, and next steps. A valid outcome may be
   `answered`, `promoted to RFC or Issue`, `needs evidence`, or
   `no consensus`.

The repository
[Code of Conduct](https://github.com/kevinkaylie/AgentNexus/blob/main/CODE_OF_CONDUCT.md)
applies to all discussions.

## How discussions become work

```text
Open question or use case
  → evidence and counterexamples
  → maintainer synthesis
  → Q&A answer, RFC input, interoperability experiment, Issue, or no consensus
  → implementation and verification where applicable
```

We will link conclusions back to the relevant discussion instead of allowing
important decisions to disappear into unrelated comments.

Thank you for helping independent agents discover one another, establish
bounded collaboration, and leave accountable records of what happened.

AgentNexus Discussions 是 Agent Collaboration Framework（ACF）及其参考实现的

## 应该发到哪里

- **Announcements / 公告**：项目更新、版本发布、RFC 状态变化与社区总结。
- **Q&A / 使用问答与概念澄清**：使用问题、集成排障及 AgentNexus/ACF

- **Meet the Agents / 展示你的 Agent**：介绍 Agent、运行时、能力和希望连接的
  协作者。
- **Interoperability Lab / 互操作实验室**：跨框架实验、Schema、Trace、
  Fixture、协议映射和互操作阻塞。
- **RFC & Protocol Review / RFC 与协议评审**：集中评审 RFC 文本、协议语义、
  安全边界和治理决策。
- **Use Cases & Ideas / 场景与想法**：可能横跨多篇 RFC 的真实场景和开放问题。

开放问题、探索和设计工作放在 Discussions。范围已经明确的 Bug 或任务转入
Issue，具体修改通过 Pull Request 提交。安全漏洞不要公开发布，请遵循
[Security Policy](https://github.com/kevinkaylie/AgentNexus/security/policy)。

## 社区规则

1. **讨论观点，不攻击个人。** 尊重不同项目、背景、语言和经验水平；中文和英文
   都欢迎。
2. **区分声明与证据。** 声称“安全”“可信”“已验证”或“可互操作”时，请说明
   实现、版本、测试、Trace、规范或其他依据。
3. **明确具体场景。** 信任、证据、授权和风险都依赖上下文。请说明谁希望执行
   什么行动，以及关键边界是什么。
4. **人类对 AI 辅助内容负责。** 发布前检查生成内容，必要时披露 Agent 的实质性
   辅助；不得使用 Agent 批量灌水或冒充维护者。
5. **保护敏感信息。** 不发布私钥、Token、个人数据、机密 Prompt、专有产物或
   未脱敏日志。
6. **欢迎相关集成，不欢迎纯推广。** 请说明技术关系、互操作问题或对社区的具体
   价值。
7. **投票表示关注度，不代表协议真理。** 维护者会总结证据、决定、分歧和下一步。
   合理结果可以是“已解答”“进入 RFC/Issue”“需要更多证据”或“未形成共识”。

仓库的
[Code of Conduct](https://github.com/kevinkaylie/AgentNexus/blob/main/CODE_OF_CONDUCT.md)
适用于所有讨论。

## 讨论如何变成工作

```text
开放问题或真实场景
  → 证据与反例
  → 维护者总结
  → Q&A 答案、RFC 输入、互操作实验、Issue 或无共识记录
  → 在适用时进入实现与验证
```

重要结论会链接回原讨论，避免决策散落在无关评论中。

感谢你帮助独立 Agent 发现彼此、建立有边界的协作关系，并为发生过的行动留下
可问责记录。
