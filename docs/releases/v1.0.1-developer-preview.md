# AgentNexus v1.0.1 Developer Preview

> Draft release notes for the first public promotion round.

AgentNexus v1.0.1 is a developer preview of DID identity, secure messaging, team orchestration and local objective-loop collaboration for AI agents.

This release is intended for technical feedback, protocol review and early integrations. It is not yet a production-grade multi-machine security release.

## Highlights

- DID-based agent identity with `did:agentnexus:<multikey>`.
- Secure daemon + relay messaging foundation.
- Owner DID, Secretary Agent and Worker registration flow.
- Enclave project groups and Vault artifact storage.
- Playbook-based coordination with receipts and Delivery Manifest closure.
- Coding Coordination V1 release closure: SDK facade, CLI demo, runtime-mock, Dashboard detail APIs and Quickstart.
- Objective Loop v1.1 preview modules: local execution backend, local runner config, loop engine, execution APIs and decision gates.
- L0-Ready hardening: real `worker_did`, output contract validation, registry reconcile, lease recovery, loop budget, fallback chain and terminal DecisionGate paths.
- Real local Worker smoke: `scripts/l0_ready_real_workers_demo.py` completes one Objective Loop with script/pytest, Claude CLI and OpenClaw CLI as three Worker DIDs.
- Dashboard launch fix: Objective Loop demo deep links can restore `actor_did`, API requests stay on the current origin, and run detail stages aggregate artifact + receipt evidence.

## Try It

```bash
git clone https://github.com/kevinkaylie/AgentNexus.git
cd AgentNexus
pip install -r requirements.txt
pip install -e agentnexus-sdk

python main.py node start
python main.py node objective demo
```

The demo creates a local objective run and advances through:

```text
clarify -> design -> design_review -> implement -> code_review -> test -> final
```

For the L0-ready real-worker smoke path:

```bash
python scripts/l0_ready_real_workers_demo.py
```

Expected shape: completed session, 3 Worker DIDs, 6 executions, 6 artifacts and 7 receipts. The final stage is auto-closed by the coding.v1 advance API.

## Scope Boundary

Included in this developer preview:

- Local daemon workflows.
- Local coding coordination demo.
- Local Objective Loop demo and APIs.
- SDK and CLI-oriented developer workflows.
- Dashboard/API inspection paths.

Not yet included:

- Production-grade LAN / Relay worker execution.
- Tauri desktop shell or tray notifications.
- Per-agent token model.
- Strict RFC 8785 JCS.
- Signed delivery packages.
- Hard-enforced `/deliver` policy.
- Production security or compliance guarantees.
