# 社区线索台账

本目录区分公开说明与本地运营记录。此 README 由 Git 跟踪，可随仓库公开；实际线索状态、联系人、待回复内容保存在被 Git 忽略的 `threads/local-ledger.md`，不作为对外发布材料。

本地台账记录上次核查时间和来源，不能把历史快照写成当前进展。重新核查前，不据旧记录判断合作意向、回复时限或对方身份。线索 ID 统一采用小写的项目短名加议题编号，例如 `a2a-1672`；完整仓库及 Issue 编号另列，避免大小写混用或重复 ID。

拟公开讨论草案放在由 Git 跟踪的 `docs/community/`；它们属于仓库材料，发布到外部论坛前仍须由维护者逐条核对事实和措辞。本地台账不自动同步到公开讨论，也不触发自动回复。角色统一称“维护者”“项目方”“参与者”，不使用内部角色称谓代替真实责任人。
